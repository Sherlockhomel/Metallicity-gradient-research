# Metallicity Gradient Research

面向 **z > 2 星系气相金属丰度与梯度研究**的 JWST NIRSpec IFU 观测计划目录。网站汇总公开 proposal、科学源、观测配置和相关论文，帮助研究者筛选候选样本，并追溯每项判断的资料出处。

**浏览网站：** [https://sherlockhomel.github.io/Metallicity-gradient-research/](https://sherlockhomel.github.io/Metallicity-gradient-research/)

## 网站内容

- **研究目录：** 按等级、源名称、PID、周期和研究标签搜索筛选。
- **项目详情：** 逐源红移与类型、IFU配置、计划与实际观测、曝光信息、诊断线覆盖及官方资料入口。
- **相关论文：** 整理方法、结果和限制，区分整体丰度、二维丰度分布与径向梯度。
- **样本统计：** 显示 proposal 等级数量、去重后的 A 类研究源数量及红移分布，提供源清单和 CSV 下载。
- **检索审计：** 保留纳入、排除、待确认记录及公开资料访问缺口。

## 分级依据

分级依据计划中的**科学源类型、红移和 IFU 配置所支持的气相丰度诊断**。

- **A：** 至少一个 z > 2 普通星形成星系，配置支持可用的气相丰度诊断；单源也可归 A。
- **B：** 有研究潜力，但 AGN、类星体宿主、强透镜或混合电离来源需要额外分析。
- **C：** 源的物理性质或配置存在明确限制，项目详情说明具体原因。
- **未定级：** 计划资料不足以判断关键条件。

混合项目有合格 A 类源时，项目归 A；其他源仍保留各自评级。Merger、特殊选样和已有梯度作为标签。背景、定位与标定目标不参与研究源计数。


## 源码与本地使用

主要修改入口：

- `styles.css`、`app.js`、`statistics.js`：外观与交互。
- `data/proposal_selection.json`：计划分级与项目说明。
- `data/source_registry.json`：逐源信息与别名。
- `data/independent_sources.json`：独立源去重与群体计数。
- `scripts/`：构建、验收与打包脚本。
